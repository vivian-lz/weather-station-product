# Weather Station

For reference, I wanted to add context as to what exactly this is.

This is a Weather Station I built with an Arduino Uno in 2022-23 for my Project-Based Programming class 
during my senior year of high school (as the pretty much only hardware based project in the class).

The code in this repo programs a BME280 sensor to measure temperature, humidity, pressure, and approximate 
altitude and displays the result to an LCD. In addition, it has an RGB light that flashes 5 different colors 
based on how hot or cold the temperature is outside.
